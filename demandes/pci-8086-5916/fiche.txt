PCI 00:02.0 · 8086:5916 · classe 03 00 00, révision 0x02
Sous-système : 1028:081c
En-tête de type 0 (appareil) ; une seule fonction
Commande 0x0007 : entrée-sortie ; mémoire ; maître du bus (DMA) ; interruptions de ligne permises
État 0x0010 : capacités ;
Zone 0 : mémoire 64 bits, 0xee000000, 16 Mio
Zone 2 : mémoire 64 bits, préchargeable, 0xd0000000, taille non mesurée
Zone 4 : entrée-sortie, 0xf000, taille non mesurée
(L'affichage : seule sa zone 0 est mesurée ; la zone 2 contient l'image de l'écran.)
Interruption de ligne : broche INTA, ligne 255 (valeur du firmware ; Aiwos se sert des MSI ou de l'IO-APIC)
Capacités :
  0x40 propre au fabricant (09), 12 octets
  0x70 PCI Express (10), v2 : intégré au complexe racine ; charge utile jusqu'à 128 octets
  0xac MSI (05) : coupées ; 32 bits ; 1 message(s) demandé(s), 1 accordé(s) ; masquage par message : non
  0xd0 gestion de l'énergie (01), v2 : en D0 ; D1 non, D2 non
Capacités étendues (espace de 4 Kio, table MCFG) :
  0x100 inconnue (001b), v1
  0x200 inconnue (000f), v1
  0x300 inconnue (0013), v1
