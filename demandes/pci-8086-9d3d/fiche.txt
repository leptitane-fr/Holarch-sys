PCI 00:16.3 · 8086:9d3d · classe 07 00 02, révision 0x21
Sous-système : 1028:081c
En-tête de type 0 (appareil) ; plusieurs fonctions
Commande 0x0000 : interruptions de ligne permises
État 0x00b0 : capacités ;
Zone 0 : entrée-sortie, 0xf0a0, 8 octets
Zone 1 : mémoire 32 bits, 0xef255000, 4 Kio
Interruption de ligne : broche INTD, ligne 255 (valeur du firmware ; Aiwos se sert des MSI ou de l'IO-APIC)
Capacités :
  0x40 MSI (05) : coupées ; 64 bits ; 1 message(s) demandé(s), 1 accordé(s) ; masquage par message : non
  0x50 gestion de l'énergie (01), v3 : en D0 ; D1 non, D2 non ; garde son état en D3hot
