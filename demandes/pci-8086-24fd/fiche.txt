PCI 02:00.0 · 8086:24fd · classe 02 80 00, révision 0x78
Sous-système : 8086:0050
En-tête de type 0 (appareil) ; une seule fonction
Commande 0x0000 : interruptions de ligne permises
État 0x0010 : capacités ;
Zone 0 : mémoire 64 bits, 0xef000000, 8 Kio
Interruption de ligne : broche INTA, ligne 255 (valeur du firmware ; Aiwos se sert des MSI ou de l'IO-APIC)
Capacités :
  0xc8 gestion de l'énergie (01), v3 : en D0 ; D1 non, D2 non ; réveil (PME) depuis D0 D3hot D3froid
  0xd0 MSI (05) : coupées ; 64 bits ; 1 message(s) demandé(s), 1 accordé(s) ; masquage par message : non
  0x40 PCI Express (10), v2 : point terminal ; charge utile jusqu'à 128 octets ; lien : 2,5 GT/s ×1 (au plus 2,5 GT/s ×1) ; ASPM permis L1, en service L1
Capacités étendues (espace de 4 Kio, table MCFG) :
  0x100 rapport d'erreurs avancé (AER) (0001), v1
  0x14c tolérance de latence (LTR) (0018), v1
  0x154 sous-états L1 (L1SS) (001e), v1
